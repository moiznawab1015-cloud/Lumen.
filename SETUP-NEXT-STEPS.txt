NEXT STEPS TO PUBLISH
1. Extract this ZIP. Open the `lumen` folder; upload the CONTENTS of that folder to a new PRIVATE GitHub repository named `lumen`.
2. Open the existing `lumen` project in Vercel. Go to Settings > Git and connect that GitHub repository.
3. Confirm the project root is the repository root. Install command: `npm install`. Build command: `npm run build`.
4. Deploy from Vercel. Check the build logs if it fails; do not invite users until signup, login, uploads, posts, Reels, follows, DMs, and moderation are tested.
5. After Vercel gives you a deployment domain, open Supabase > Authentication > URL Configuration. Set Site URL to that domain and add the domain to Redirect URLs.
6. Create your own account in Lumen. To make it an admin, run this SQL in Supabase SQL Editor, replacing your username:
   update profiles set role = 'admin' where username = 'yourusername';
   Then open /admin on the deployed site.

LOCAL DEVELOPMENT
1. Copy `.env.example` to `.env.local`.
2. Set NEXT_PUBLIC_SUPABASE_URL to the Supabase project URL above.
3. Set NEXT_PUBLIC_SUPABASE_ANON_KEY to the project's publishable/anon key from Supabase API settings.
4. Run: npm install
5. Run: npm run dev
